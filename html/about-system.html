🎯 Objective Section (Normal Baseline Risk)

The objective of Use Case is to build an AI-driven heatwave monitoring system that continuously analyzes temperature data and sends automated early warnings.

  • Predict maximum temperatures across seven IMD regions.
  • Deploy IoT AWS hardware units for ground validation.
  • Disseminate advisories to citizens, farmers, and healthcare workers.

📡 Data Sources Section (Heat Watch Severity)

The system collects data from the India Meteorological Department (IMD) repository (1951-2026). Key data attributes include Timestamp, Latitude, Longitude, and Maximum Temperature.


👥 Stakeholders Section (Severe Alert Severity)

Primary beneficiaries include Disaster Management Authorities, Municipal Corporations, Public Health Agencies, and General Citizens.
